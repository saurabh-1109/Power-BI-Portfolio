# Order Analysis Dashboard

## 📊 Project Overview

The **Order Analysis Dashboard** is an interactive Power BI project designed to analyze sales and order performance. It transforms raw business data into an easy-to-understand dashboard that helps track key KPIs, identify sales trends, and understand product and order performance.

The project demonstrates practical skills in **Power BI, Power Query, DAX, data cleaning, data modeling, and interactive dashboard design**.

## 🎯 Objectives

- Monitor overall sales and order performance
- Track total sales, total orders, and quantity sold
- Analyze average order value
- Understand monthly and quarterly sales trends
- Identify top-performing products
- Compare product-level sales and quantity performance
- Provide interactive filtering for business analysis

## 📌 Key KPIs

- **Total Sales**
- **Total Orders**
- **Total Quantity Sold**
- **Average Order Value**

## 📈 Dashboard Analysis

The dashboard focuses on:

### Sales Performance
- Overall sales performance
- Sales trends over time
- Monthly and quarterly comparisons

### Order Analysis
- Total order volume
- Order trends over time
- Average order value

### Product Analysis
- Product-level sales performance
- Quantity sold by product
- Identification of high-performing products

### Interactive Analysis
Users can interact with the dashboard using filters and slicers to explore the data from different perspectives.
