# Power BI Portfolio

Welcome to my Power BI portfolio.

This repository contains my Power BI dashboards and data analysis projects.

## Projects

### Dairy Sales Analysis

A Power BI dashboard analyzing dairy sales performance, orders, quantities, and product-level trends.

**Tools:** Power BI, DAX, Power Query, Excel

### Order Analysis Dashboard 
 Order Analysis Dashboard is an interactive Power BI project designed to analyze sales and order performance. It transforms raw business data into an easy-to-understand dashboard that helps track key KPIs, identify sales trends, and understand product and order performance.

**Tools:** Power BI, DAX, Power Query, Excel

### Blinkit Sales Analysis Dashboard
The dashboard provides a business-focused view of total sales, average sales, item count, ratings, outlet establishment trends, fat content, item categories, outlet size, outlet location, and outlet type.

**Tools:** Power BI, DAX, Power Query, data visualization, KPI development, and business analysis.
