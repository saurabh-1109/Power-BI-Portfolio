# Dairy Sales Analysis

## Project Overview

This Power BI project analyzes dairy sales data to identify sales performance, order trends, product performance, and quantity distribution.

## Dashboard

![Dairy Sales Dashboard](dashboard-screenshot.png)

## Key KPIs

- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value

## Analysis

The dashboard provides insights into:

- Sales trends over time
- Product performance
- Quantity sold
- Order volume
- Monthly and quarterly performance
- Product-level sales analysis

## Tools Used

- Power BI
- DAX
- Power Query
- Microsoft Excel
