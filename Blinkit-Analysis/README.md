linkit Sales Analysis Dashboard

📊 Project Overview

The Blinkit Sales Analysis Dashboard is an interactive Power BI
dashboard created to analyze Blinkit outlet and product sales
performance.

The dashboard provides a business-focused view of total sales, average
sales, item count, ratings, outlet establishment trends, fat content,
item categories, outlet size, outlet location, and outlet type.

This project demonstrates practical skills in Power BI, DAX, Power
Query, data visualization, KPI development, and business analysis.

🎯 Objectives

Analyze overall Blinkit sales performance

Compare sales across different outlet types

Understand the impact of outlet size and location on sales

Analyze product performance by item type

Compare sales based on fat content

Track outlet establishment trends over the years

Analyze average customer ratings

Build an interactive dashboard for business reporting
